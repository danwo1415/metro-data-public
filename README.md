# 六城地鐵路線規劃器 v2.4.7-HK

## 本版新增
- 在第一段乘車卡片右側顯示所查起點站的最近三班港鐵實時班次。
- 固定格式：`臨近班次：HH:MM；HH:MM；HH:MM`。
- API 無資料、網路失敗或班次不會行經本段終點時，顯示：`臨近班次：暫無訊息`。
- 只顯示正確路綫、起點站、行車方向及會行經本段下車站的列車。
- 實時資料直接來自香港政府／港鐵 Next Train API，快取 10 秒以配合官方更新頻率。

## 保留修正
- 刷新資料不會打開瀏覽器。
- 刷新成功顯示「已刷新」，成功或失敗都會結束刷新狀態。
- App 啟動時檢查首末班資料版本，遠端有新版時提示使用者刷新。

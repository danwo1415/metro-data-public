# 六城地鐵路線規劃器 v2.4.11-HK

## 本版新增
- 城市列下方新增天氣資訊列，依序顯示溫度、濕度、紫外線指數及 PM2.5。
- 顯示順序調整為：城市 → 天氣資訊 → 語言選擇 → 起點／終點。
- 路線摘要在總時間前顯示票價。
- 票價採用港鐵官方公開 CSV 的成人八達通票價；資料由 App 原生網路層直接讀取，避免 WebView 跨域問題。
- 溫度、濕度及紫外線來自香港天文台；PM2.5 來自環境保護署污染物濃度資料。
- 天氣資料啟動時載入、回到前景時更新，並每10分鐘自動更新一次。

## 資料來源與顯示規則
- 溫度：香港天文台站。
- 濕度：香港天文台站。
- 紫外線：天文台即時 UV 指數；非公布時段或無資料時顯示 `--`。
- PM2.5：優先採用中西區一般監測站的最新每小時數值；無資料時顯示 `--`。
- 票價：優先顯示港鐵官方成人八達通票價；官方檔案未能對應的行程顯示「票價暫無訊息」。

## 既有功能
- 三語介面及自動規劃。
- 每10秒更新起點站最近三班列車時間。
- 首末班資料版本檢查及手動刷新。

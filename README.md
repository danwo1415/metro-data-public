# 六城地鐵路線規劃器 v2.4.8-HK

## 本版更新
- 香港起點站的「臨近班次」在路線結果停留期間每 10 秒自動重新讀取港鐵官方 Next Train API。
- 切換路線、起終點或規劃模式時，會停止舊路線的更新並立即載入新路線班次。
- App 進入背景後停止輪詢；回到前景時立即更新一次，之後恢復每 10 秒更新。
- 自動更新時保留畫面上的上一筆結果，避免每 10 秒短暫閃成「暫無訊息」。
- API 無資料或讀取失敗時仍顯示「臨近班次：暫無訊息」。

## 資料來源
- 即時臨近班次直接讀取香港政府／港鐵 Next Train API。
- 首末班資料沿用 `metro-data-public` 的版本檢查與手動刷新機制。

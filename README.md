# 六城地鐵路線規劃器 v2.4.9-HK

## 本版更新
- 移除「查詢路線」按鈕；選中起點或終點後立即自動重新規劃。
- 完整輸入唯一且精確匹配的站名、英文名、拼音或站碼後，也會自動確認並規劃；按 Enter 可選取首個候選站。
- 原按鈕位置改為三語切換：繁體中文、简体中文、English。
- 語言切換後，城市、站名、路綫名、輸入欄、路線結果、首末班、臨近班次、更新提示、錯誤及公告文字全部立即刷新。
- 語言選擇會保存在手機，下次啟動沿用。
- 保留每10秒更新香港起點站最近三班列車的功能。

## 資料來源
- 即時臨近班次直接讀取香港政府／港鐵 Next Train API。
- 首末班資料沿用 `metro-data-public` 的版本檢查與手動刷新機制。

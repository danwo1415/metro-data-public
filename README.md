# 六城地鐵路線規劃器 v2.4.14-HK

## 本版修正
- 紫外線改用香港天文台「最新十五分鐘平均紫外線指數」CSV，不再使用 `rhrread` 的過去一小時口徑。
- 官方數據源：`latest_15min_uvindex.csv`，香港時間 07:00 至 18:00 每 15 分鐘更新。
- App 每 10 分鐘重新讀取天氣；網路暫時失敗時保留手機內最近一次成功取得的十五分鐘紫外線數值。
- CSV 最新一筆若為 `N/A`，畫面顯示 `--`，不以一小時紫外線資料替代。
- PM2.5、票價、三語、自動規劃及每 10 秒臨近班次功能維持不變。

## 必要配套
PM2.5 仍需先把 `hk-environment-auto-update-v1.zip` 安裝到 `danwo1415/metro-data-public`，讓它生成 `hk-environment.json`。

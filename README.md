# 六城地鐵路線規劃器 v2.4.12-HK

## 本版修正
- 修正 PM2.5 長期顯示 `--` 的問題。
- EPD 請求改用瀏覽器相容標頭，避免 AQHI 伺服器拒絕 Android 原生 User-Agent。
- PM2.5 採三級官方資料回退：EPD XML → DATA.GOV.HK Filter API → EPD 公開摘要頁。
- XML 同時使用 DOM 與正則雙重解析；DATA.GOV.HK JSON 採遞迴欄位解析。
- 優先顯示中西區一般監測站的最新 PM2.5，無資料時才顯示 `--`。
- 溫度、濕度、紫外線、票價、三語、自動規劃及每10秒臨近班次功能維持不變。

## 顯示單位
PM2.5 顯示為 `µg/m³`，環保署資料每小時更新。
